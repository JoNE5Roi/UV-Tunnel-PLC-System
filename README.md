An industrial automation upgrade project executed during my Manufacturing Engineering Internship at CPRAM Co., Ltd. The project focused on transforming a legacy direct relay control system of a UV Tunnel into a modern, highly reliable **PLC & HMI-based architecture**.

## 🎯 Project Objectives
* **System Modernization:** Upgrade the old direct control system to a Programmable Logic Controller (PLC) for better stability and scalability.
* **User Experience (UX):** Design and implement a Human-Machine Interface (HMI) for intuitive monitoring and control by operators.
* **Safety & Reliability:** Integrate advanced fault handling and safety interlocks to prevent operational hazards.

## 🛠️ Technical Stack & Skills Demonstrated
* **PLC Programming:** Ladder logic design, internal memory mapping, and I/O assignment.
* **HMI Development:** UI/UX design for industrial screens, alarm management, and real-time data visualization.
* **System Integration:** Wiring, installation, and commissioning of the new control panel.
* **Technical Documentation:** Authored comprehensive Operation Manuals, I/O mapping tables, and fault handling procedures.

## ⚙️ System Architecture Overview
**(Note: Due to company confidentiality, source codes and specific proprietary details are not disclosed here. Below is a conceptual overview of the implemented logic.)*

1. **Input Stage:** Sensors and safety switches interface directly with the PLC input modules.
2. **Processing (PLC):** Custom ladder logic processes conditions for conveyor speed, UV lamp operation, and safety interlocks.
3. **Output Stage:** PLC output modules trigger relays/contactors to drive motors and UV systems.
4. **Monitoring (HMI):** Displays real-time machine status, active alarms, and allows for parameter adjustments (e.g., speed, timer).
